## The entry

> Tuesday again. The banners are barely dry from last week, and here you are, sword up, destiny polished, shouting my name like it is the first time. Sit down. No, stand if you must. The traps are set, the lava is warm, the speech is mostly memorised, and I left the gate unlocked so we could skip the siege. My generals run a book on how long you last this time. You will fall, and still rise again by dawn, because that is what chosen ones do. I conquered nine kingdoms for this appointment, hero, and prophecy offers no refunds.

529 characters, 100 words, 1 line. The Dark Lord is exhausted because the hero keeps respawning — the "final battle" happens every Tuesday, the Chosen One never stays dead, and the Dark Lord has started leaving the castle door unlocked just to get it over with. The tiredness is never announced: it lives in the routine — banners barely dry from last week, a speech mostly memorised, an appointment prophecy offers no refunds for.
